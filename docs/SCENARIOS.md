# 夜班反例

18位员工各有10月1日22点进、10月2日06点出。02点至03点休息，实际7小时，前两小时是假日3倍，次日5小时正常1倍，20元时薪合计220元。直接把整个夜班按归属日计假日会错算420元。脏批额外含缺时薪、冲突打卡、BOM、短行、空行与重复表头。

# 替班裁决

E201排了10月1日夜班，E202实际顶班打卡，E203正常出勤。截止10月31日审批SUB-1仍是待批：E202的220元挂起留痕不进实发，E203的220元可付，应发440=实发220+挂起220。审批在10月30日批准后重跑：E202的220元翻转为可付，旧批次失效禁止导出。审批条款改为调休时：E202不付现，420分钟记为调休。审批在11月2日才批（晚于截止）：本期仍挂起，截止改期后重跑才翻转。E204也打卡同一排班班次时两人同顶一班，全部挂起，同一分钟不会记给两个人。
